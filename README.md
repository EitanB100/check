# Polymarket Prediction Markets Dashboard

This project contains an embedded dashboard of multiple Polymarket prediction markets.

## Features

- Displays various prediction markets in a responsive grid layout.
- Dark mode toggle for better viewing experience.
- Each market includes structured data for SEO.

## Usage

1. Open `index.html` in a web browser to view the dashboard.
2. Use the toggle in the top-right to switch between dark and light modes.
3. To run a local server (recommended for proper iframe loading):
   - Install Python if not already installed: `sudo apt update && sudo apt install python3`
   - Run: `python3 -m http.server 8000`
   - Open `http://localhost:8000` in your browser.

The dashboard includes markets on topics like Cuban regime, Trump meetings, Iran leadership changes, and more.
